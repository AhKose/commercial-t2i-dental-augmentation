# Dataset Visualizations

Visual summaries of the patient-level impacted-teeth task derived from the DENTEX dataset, and of the technically screened synthetic pools. The real DENTEX radiographs themselves are not redistributed; the example images below are shown for illustration only. Real example images: S. Er, "DENTEX Challenge 2023," Zenodo, 2023, doi: 10.5281/zenodo.7812323.

- **`dataset_examples.png` / `.pdf`**
  Representative panoramic radiographs: real impacted patients (DENTEX; the impacted-tooth annotations are drawn as boxes labeled with their FDI tooth number), real non-impacted patients (DENTEX), and technically screened synthetic impacted-class images from GPT Image 1 and Nano Banana 2. Examples were drawn with a fixed random seed; the file names are listed in `dataset_examples_files.csv`.

- **`dataset_distribution.png` / `.pdf`**
  (a) Patient-level class distribution in the full dataset (254 impacted / 451 non-impacted, 1.78:1) and in each of the three stratified outer test folds. (b) Number of annotated impacted teeth per impacted patient. (c) Position of the 604 annotated impacted teeth by FDI tooth number; all impacted-tooth annotations in DENTEX are third molars (18, 28, 38, 48). Numbers: `dataset_class_distribution.csv`, `impacted_teeth_per_patient.csv`, `impacted_tooth_positions_fdi.csv`.

- **`dataset_feature_pca.png` / `.pdf`**
  Two-dimensional principal component analysis of the radiology-domain image features used for the KID analysis (TorchXRayVision DenseNet-121, 1024-d global-average-pooled features). The PCA is fitted on the 705 real radiographs only, and the 35 + 35 synthetic images are projected into the same space. Coordinates: `dataset_feature_pca_coordinates.csv`. As with KID, this feature space is a distributional descriptor and not a measure of dental anatomical realism.

Generated by `dataset_visualization.py`, which will be released in `../../code/` together with the rest of the source code.
